# R dependencies

The main analysis uses these R packages:

- `readxl`
- `pmr`
- `PlackettLuce`
- `prefmod`
- `qvcalc`
- `smacof`
- `grid` (included with base R)

In R, install the packages available from CRAN:

```r
install.packages(c("readxl", "pmr", "PlackettLuce", "prefmod", "qvcalc", "smacof"))
```

The exact R and package versions used for the original project were not supplied. Some packages may require additional system dependencies or version-specific installation steps. Run the script from the repository root with the survey spreadsheet at `data/pare-1331-finch.xlsx`.
